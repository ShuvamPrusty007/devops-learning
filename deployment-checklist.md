# Application Deployment Checklist

## Pre-Deployment Checks
- Confirm deployment approval.
- Verify the application build.
- Check configuration and environment variables.
- Confirm database connectivity.
- Review pending incidents.

## Deployment Steps
- Start the deployment.
- Monitor deployment logs.
- Verify application services.
- Perform basic smoke testing.

## Post-Deployment Checks
- Confirm application availability.
- Check monitoring alerts.
- Verify critical application functionality.
- Update the deployment record.

## Rollback Plan
- Identify the previous stable version.
- Follow the approved rollback procedure.
- Verify application health after rollback.
