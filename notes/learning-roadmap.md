# Cloud and DevOps Learning Roadmap

**Learning period:** 17 November 2026 – 31 March 2027

**Career objective:** Transition from Production/Application Support into Cloud, DevOps and SRE-oriented roles.

**Target compensation:** 10–12 LPA (aspirational target, dependent on skills, interviews and market conditions).

**Study commitment:** 2–3 hours daily, six days per week.

## Phase 1: Linux, Networking and Git

**17 November – 30 November 2026**

### Linux
- Linux fundamentals and architecture
- Filesystem and navigation
- File and directory operations
- Search and text processing
- Permissions and user management
- Processes and resource monitoring
- Services and logs

### Networking
- IP addressing
- Subnets and gateways
- DNS
- TCP and UDP
- Ports
- HTTP and HTTPS
- Networking commands

### Remote access
- SSH
- SSH authentication
- SFTP
- FTP vs SFTP

### Git and GitHub
- Version control fundamentals
- Repositories
- Working directory and staging area
- Commits
- Branches and merging
- GitHub remote repositories
- Push, pull and clone
- `.gitignore` and README

**Outcome:** Independently use Linux, understand networking basics and manage a GitHub repository.
